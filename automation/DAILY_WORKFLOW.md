# Build Star Daily Workflow

## Purpose

Produce one original Amazon affiliate Short for **Build Smart Tools & Materials** every day, using verifiable facts, permitted media, clear disclosures, and conservative construction-safety language.

## Schedule

- Start: 12:00 PM
- Time zone: America/Los_Angeles
- Cadence: daily
- Affiliate tracking ID: `buildsmartpic-20`
- Default category: Amazon Tools & Home Improvement Best Sellers
- Destination channel: Build Smart Tools & Materials (`@BuildSmartPicks`)
- Publish state: Public only after all gates pass

## Source of truth for “top-selling”

Amazon does not publicly expose exact unit sales for every product. Select the highest item in Amazon's visible Tools & Home Improvement Best Sellers ordering and describe it only as the observed category leader or rank at the recorded time.

Record:

- Timestamp with time zone
- Amazon category and Best Sellers Rank
- Product title and ASIN
- Product-detail URL
- Any visible “bought in past month” bucket, quoted exactly
- Screenshot or captured evidence when practical

Never invent exact sales volume. Never convert rank, review count, or a “bought” bucket into a precise unit-sales claim.

## Product eligibility gates

The selected product must:

- Be in the stated Tools & Home Improvement category
- Have a stable ASIN and a valid affiliate URL
- Be available when checked
- Not have a known active recall or obvious counterfeit warning
- Not require restricted, medical, illegal, or unsafe claims
- Have enough verifiable specifications for useful original narration
- Have product media that is permitted for this use
- Not have been featured in the previous 30 days, unless no eligible alternative is available

If the top item fails, inspect the next ranked item and log the reason for each skip.

## Media rights

Allowed sources, in order:

1. Amazon Product Advertising API image URLs and Product Advertising Content when the account and approved Site use permit it
2. Manufacturer press or affiliate assets with an explicit reuse license
3. Original footage or original graphics created for Build Star

Do not copy an Amazon advertisement wholesale. Do not use customer review photos, videos, or text. Do not remove watermarks. If permitted product imagery cannot be verified, skip the product or use a clearly original non-confusing graphic that does not imitate protected packaging artwork.

## Fact gathering

Verify key details from the current Amazon listing and, when available, the manufacturer product page. Separate facts from opinions. Do not make unsupported claims about:

- Performance or durability
- Safety, certification, or code compliance
- Price, discount duration, inventory, or future availability
- “Best,” “guaranteed,” or professional suitability

For construction and tool products, include the relevant caveat: follow manufacturer instructions, use appropriate PPE, comply with local codes, and consult a licensed professional when required.

## Video specification

- Format: vertical 9:16
- Target duration: 20–45 seconds
- Resolution: 1080 × 1920
- Content: original hook, 2–4 verified features, practical use context, safety note where relevant, and affiliate call to action
- Audio: original narration and royalty-free or original music only
- Captions: burned in and checked for accuracy
- Visuals: permitted product images plus original motion, typography, and layout

## Required disclosure

Include this exact sentence in the description, above or adjacent to the affiliate link:

> As an Amazon Associate I earn from qualifying purchases.

Also disclose the commercial relationship clearly in the video or opening description, and use the YouTube paid-promotion declaration.

## YouTube upload checklist

Before publishing, verify:

- Signed-in channel is **Build Smart Tools & Materials** (`@BuildSmartPicks`)
- Title and description match the selected product and ASIN
- Affiliate link uses `buildsmartpic-20`
- Required Amazon Associates disclosure is present
- Paid promotion is marked
- AI/synthetic-content setting is answered truthfully
- Audience is **No, it is not made for kids**
- Visibility is **Public**
- Copyright checks show no blocking issue
- Construction-safety caveat is present when relevant

If the active channel is wrong, rights are unclear, facts conflict, upload limits apply, or checks show an issue, do not publish. Report the block and preserve the completed draft privately until resolved.

## Daily log

For each run, record:

- Date and start/finish time
- Product, ASIN, category rank, and evidence URL
- Skip reasons, if any
- Affiliate URL
- Media sources and usage basis
- Script and factual sources
- Rendered file path
- YouTube video URL and video ID
- Visibility and settings confirmation
- Errors or unresolved checks

Never commit OAuth credentials, API secrets, browser cookies, or YouTube tokens to this repository.
